**Có gì mới**

- Icon ứng dụng mới và giao diện Cài đặt/Giới thiệu đồng bộ hơn.
- Kéo được cửa sổ khi đang mở Cài đặt.
- Thanh thao tác ảnh gọn hơn: nút chỉ hiển thị icon, rê chuột để xem tên.
- Thêm Sao chép và Cắt ảnh; trên Mac dùng Option + Command + V trong Finder để di chuyển.
- Sửa thao tác xoay ảnh trên Windows và bỏ cửa sổ PowerShell bật lên khi xoay.
